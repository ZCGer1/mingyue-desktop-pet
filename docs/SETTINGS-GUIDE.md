# 设置页操作指南

当前设置页固定七个一级页面，默认窗口 880×700，最小 720×560。截图由 E2E 真实渲染生成：

```bash
npm run build
MINGYUE_E2E_SETTINGS_SCREENSHOTS=1 npx playwright test tests/e2e/settings-layout.spec.ts
```

截图位于 `docs/assets/settings/`，是开发构建（虚构后端、无 API Key）的画面，不代表真实模型或真实浏览器扩展已验收。
字段的完整归属与新入口见 [SETTINGS-FIELD-MIGRATION.md](SETTINGS-FIELD-MIGRATION.md)。

## 1. 概览：配置流程

![配置流程](assets/settings/01-overview-wizard.png)

首次进入时，概览直接提供分步配置：

```text
API → 网页 → B 站 → 应用 → 屏幕 → 文件 → 作品空间 → 陪伴 → 记忆 → 完成
```

- 每步都嵌入设置页使用的同一份表单，展开“高级”可以看到该能力的低频参数。
- **保存并继续**只提交当前步骤拥有的字段；其他页面或步骤的未保存草稿不会被顺带保存。
- **跳过**不改任何已保存配置，只记录“已跳过”。
- 返回上一步可以继续编辑未提交的内容，步骤状态会显示“未保存”。
- **完成**汇总六项能力的真实状态，并提供“自主与授权”和“其他设置”；完成后概览折叠为精简状态。

配置流程的进度与跳过记录只保存在设置页的界面偏好里，不写 API Key，也不写任何权限同意。

![概览](assets/settings/01-overview.png)

完成配置后，概览只保留：

- 她现在在做什么（一句话状态）与模型/探索/能力计数。
- 六项能力的名称、状态（就绪、部分可用、未授权、已关闭、等待连接、缺少同意、目录不可用、授权已到期、运行异常）、第一个阻塞原因和“配置”入口。
- **重新配置**（从现有配置初始化，不重置）与**打开聊天**。
- 运行控制：**立即停止**（取消当前任务并释放键鼠）、**暂停/恢复探索**、**安静/恢复主动说话**、**撤销授权**入口。

任务、发现和各类记录在「活动与任务」，不在概览重复展示。

## 2. 陪伴与外观

![陪伴与外观](assets/settings/03-companion.png)

- 身份：名字、语言、语气。
- 人格提示词：追加在内置身份与安全边界之后，上限 4000 字。
- 聊天节奏：主动聊天档位、自主 tick 的最短/最长间隔、沉默退避、唤醒最小间隔、发言后冷却、安静时段与离开电脑时的降频。
- 屏幕感知：只消费已接受的抽象摘要，不提高截图频率；显示当前状态、阻断原因、最近真正显示时间，并提供一次反馈测试。
- 完整聊天窗口、快捷输入、点击动作。
- 桌宠表现：桌宠世界开关、角色大小、减少动态效果、随机小动作、语义动作、走动总开关与随机走动、只留在当前显示器，以及归位/参数面板。
- 安静时段：只压制主动说话；自主探索按自己的节奏继续。

自主模式、探索授权与任务预算在「电脑能力 → 自主与授权」。

## 3. 电脑能力

![电脑能力 · 网页](assets/settings/04a-computer-web.png)

顶部是六项能力的紧凑状态条，下面是共用的「自主与授权」折叠组，再下面是六项能力子导航：
**网页、B 站、应用、屏幕、文件、作品空间**。一次只显示一个子页，只有当前子页建立状态轮询。

### 3.1 自主与授权

- 允许自由探索（总授权）、允许自主 tick。
- 授权状态、有效期（仅本会话 / 长期）、实际生效范围。
- 自主模式、审批策略、接管冷却。
- 任务预算与配额（单任务时长/工具次数/保留天数、会话授权有效期、每小时自动操作上限、自动备份数量、审批超时、重启恢复、是否允许本会话/始终允许授权）。
- 立即撤销授权：只撤销已保存的自由探索授权，不保存其他草稿。

### 3.2 网页

![网页](assets/settings/04a-computer-web.png)

- 状态：本机桥、扩展连接、主动浏览是否生效、当前页与接收计数。
- 常用：联网搜索与公开读取、每次询问、浏览器页面感知（显式同意）、自主使用网页/标签页、主动浏览（显式同意）、仅白名单域名。
- 扩展连接：配对码、复制/轮换 token、打开扩展文件夹、扩展目录与错误、安装步骤。
- 域名规则：允许、排除、敏感域名、自由探索排除站点。
- 高级：共享标题/摘要/小标题、摘要长度、合并窗口、事件频率、标签页上限、等待上限、搜索模板、会话预算、发现保留。

### 3.3 B 站

![B 站](assets/settings/04b-computer-bilibili.png)

启用（显式同意）、服务阶段、Python、登录、会话、今日阅读/日报/失败；
扫码登录、依赖安装（Python、主服务、本地转写、转写模型）、阅读偏好（关注词、排除词、画面辅助、本地转写、日报开关）；
高级：候选/精读上限、会话时长与工具次数、抽帧数、转写模型与体积/时长/缓存上限、日报保留天数。

### 3.4 应用

![应用](assets/settings/04c-computer-apps.png)

启用应用与系统操作（显式同意）、普通应用类别授权、打开文件/文件夹与链接；
应用白名单（扫描开始菜单、表格编辑、自定义应用）；系统动作固定七种；
高级：新安装应用继承类别授权、排除的应用。逐应用的观察/输入权限在「屏幕」。

### 3.5 屏幕

![屏幕](assets/settings/04d-computer-screen.png)

- 状态：屏幕感知、整屏共享、键鼠与截图双重同意、图片输入、观察状态、键鼠计数。
- 常用：开启屏幕感知（显式同意）、整屏画面共享（单独同意）、允许电脑操作（键鼠 + 截图两次确认）、暂停/恢复观察、立即观察一次、立即停止键鼠。
- 窗口观察：授权窗口观察、整屏/多显示器观察、结构化文本、按窗口截图。
- 应用观察与输入范围：逐应用观察/输入、运行中候选、手动添加。
- 高级：观察周期、OCR、场景保留、观察配额、窗口清单上限与轮询、输入确认与免问时长、清除免问授权、截图参数、动作等待、追加阻止的应用、固定禁止名单。

屏幕场景与事件诊断在「高级与诊断 → 屏幕诊断」。

### 3.6 文件

![文件](assets/settings/04e-computer-files.png)

可读根与写入状态、文件读取范围、磁盘范围、个人资料目录、连续编辑；
工作区；额外只读目录、文件工具额外目录、用户排除项、信任目录；笔记目录只读摘要与入口；
范围详情（只读）：统一文件范围的候选根与卷清单。

### 3.7 作品空间

![作品空间](assets/settings/04f-computer-artifacts.png)

作品/下载写入授权、浏览器普通下载许可、作品目录与笔记目录的选择/清空（含回退关系提示）。

## 4. 活动与任务

![活动与任务](assets/settings/05-activity.png)

只放任务与记录，不放配置表单：

- 自主状态：能力状态、当前调度、下一次机会、上一轮结果、实际范围阻塞。
- 进行中的任务：暂停/恢复/取消；最近结束的任务。
- 发现：打开、喜欢/少分享/别再研究、逐条删除或清空。
- 兴趣与经历：暂停/继续/结束/删除、清空。
- 任务授权：逐条撤销。
- 审批授权：本会话/始终允许的授权与清除。
- 文件撤销：最近记录与撤销最近一次/五次。
- 系统操作：最近系统动作（目标只在本机显示）。

配置任务预算与审批策略在「电脑能力 → 自主与授权」。

## 5. 模型与用量

![模型与用量](assets/settings/06-model.png)

DeepSeek API Key（主进程 DPAPI 加密）、主模型与工具模型、上下文窗口与输出上限、
thinking、图片输入、上下文预算；高级：接口地址、网络超时、软阈值/保留比例、合批参数；
用量与费用只统计本机调用。

## 6. 记忆与隐私

![记忆与隐私](assets/settings/07-privacy.png)

- 记忆开关（长期记忆、作息、自动整理）与记忆文件编辑。
- 只读行为感知：启用、暂停采样、采样间隔、空闲判定。
- 共享给模型的脱敏事件：事件唤醒、应用显示名、脱敏窗口标题、标题长度、统计保留。
- 静音与排除、她看到了什么（本机原始采样）、类别统计。
- 清空本地数据（二次确认）。

屏幕截图与整屏共享配置在「电脑能力 → 屏幕」，本页不重复。

## 7. 高级与诊断

![高级与诊断](assets/settings/08-advanced.png)

默认收起的折叠区：

- **Worlds 健康**：各 World 的开关、可用状态、工具与事件；只保留状态与跳转，不重复业务开关。
- **运行诊断**（默认展开）：运行相位、队列、令牌、自主与感知计数、日志导出。
- **屏幕诊断**：观察目标、节律、耗时、最近场景与事件链；配置在「屏幕」。
- **终端与启动**：终端开关与 Shell、命令前缀白名单、开机自启、暂停对话总线、桌宠页面维护。
- **关于与许可**：版本、许可证、上游署名、隐私承诺与故障排查。

## 保存、草稿与冲突

- 普通设置页仍使用显式保存：切换页面不会保存草稿，也不会丢弃草稿。
- 保存请求携带磁盘配置版本。磁盘被托盘或其他窗口更新时，保存返回冲突：可以“载入最新配置”（丢弃草稿）、“保留草稿并覆盖”或“放弃草稿”。
- 保存期间继续编辑时，旧快照写入磁盘，较新的编辑保持为未保存草稿。
- 配置流程每步只提交该步骤拥有的字段：请求 = 最新已保存配置 + 本步骤字段。其他页面草稿继续保留。
- 跳过不保存，也不改变已有授权；返回步骤时未提交内容会标为“未保存”。
- 撤销授权、停止操作、扫码登录、安装依赖等即时动作与参数编辑分离，不会静默保存其他草稿。

## 搜索、键盘与可访问性

- 侧栏搜索支持中文/英文关键词；按 `Enter` 直达第一条结果，`Escape` 清空。
- 支持 `#computer/files`、`#computer/exploration`、`#privacy/perception`、旧 `#security` 等直接定位；锚点会先切换到对应子页、展开必需的折叠区，再滚动并聚焦目标。
- 一级导航与六个能力子导航都可以 Tab 聚焦，焦点有 2px 可见轮廓；主题正文和状态色在卡片背景上满足 WCAG AA 对比度。
- 加载时显示“正在读取设置…”；主进程读取失败时显示可理解的错误页，而不是空白。
- 880×700 与 720×560 两种窗口尺寸下，页面与六项能力子页都不横向溢出，保存按钮始终可见。
