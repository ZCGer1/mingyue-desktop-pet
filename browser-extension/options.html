桌宠 · 网页感知

这个扩展只读取当前窗口的活跃标签页的标题、域名、正文摘要和少量小标题， 通过本机回环地址发送给桌宠。它不读取完整 URL、cookie、localStorage、表单值、 选中文本、历史记录或书签。

1. 配对

在桌宠的「设置 → 浏览器页面」中复制配对码，形状如 43123#<64 位 token>，粘贴到这里。

2. 授权与开关

真正生效还需要在桌宠「设置 → 浏览器页面」中开启页面感知并保存。任何一侧关闭都不会发送内容。

3. 状态

配对
读取中…

扩展不在本地保存页面正文；页面内容只在内存中停留到发送完成。 如果状态显示“无法连接”，请确认桌宠正在运行且页面感知已开启。

安装步骤（开发版）

  1. 在桌宠「设置 → 浏览器页面」中点击“打开扩展文件夹”。
  2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
  3. 开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择该文件夹。
  4. 回到本页，粘贴配对码并勾选同意，保存。
