# 桌宠 · 网页感知扩展

同一套 Manifest V3 扩展支持 Chrome 与 Edge。它把**当前窗口的活跃标签页**的标题、域名、
正文摘要和少量小标题发送给本机的桌宠，让桌宠知道你在看什么。

## 能力边界

- 只读当前活跃标签页；后台标签页的 DOM 变化会被忽略。
- 只发送 `location.hostname`，不发送协议、路径、查询参数或 hash。
- 不读取 cookie、localStorage、表单值、密码字段、选中文本、历史、书签或下载。
- 包含密码输入框的页面、内置敏感域名、应用设置中的敏感/排除域名，以及无痕窗口：
  一律不发送标题或正文；应用会清除旧页面。
- 页面正文不会写入 `chrome.storage`，只在内存中停留到 POST 完成。
- 未配对、未同意、已暂停或拉取不到过滤规则时，不发送页面内容。

## 安装（开发版）

1. 在桌宠「设置 → 浏览器页面」中开启页面感知并保存。
2. 点击设置页的「打开扩展文件夹」，复制顶部显示的配对码。
3. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择本目录
   （安装版位于应用安装目录的 `resources/browser-extension`）。
5. 打开扩展的「详情 → 扩展选项」，粘贴配对码，勾选授权说明，点击「保存并连接」。
6. 如需让桌宠主动浏览，点击浏览器工具栏里的扩展图标，在弹窗中勾选
   「允许主动浏览」。这是扩展侧的第二份授权，应用设置里的开关不能代替它。

## 常见问题

- **页面感知显示已连接，但桌宠说主动控制未连接**：页面感知和主动浏览是两个独立通道。
  打开扩展弹窗，确认「允许主动浏览」已勾选；若刚勾选，等几秒或刷新扩展后重试。
- **无法连接**：确认桌宠正在运行、页面感知已开启、配对码是最新的。
- **改了端口/轮换了 token**：在应用设置里重新复制配对码；轮换后旧 token 立即失效。
- **暂时不想共享**：在扩展弹窗里勾选「暂停发送」，或在应用设置里关闭页面感知。
- **敏感站点太多**：在应用设置的域名排除列表里添加；扩展每 5 分钟刷新一次过滤规则，
  拉取失败时保守停止发送。
